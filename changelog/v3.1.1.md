# v3.1.1 — Windows `hosts.yml` 默认路径识别与 `.cmd` 兼容

> 发布日期：2026-11-27

## 改进（Changed）

- 在 [`src/config.js`](../src/config.js) 新增 `defaultGhConfigDir()`：在 Windows（`win32`）下自动检查 `%APPDATA%\GitHub CLI\hosts.yml`（回退 `~/.config/gh`），并在 `GH_CLI_PATH` 指向 `.cmd`/`.bat` 时兼容调用 `gh auth token`。
- 更新 `tokenHint()`，针对 Windows 与 Linux/macOS 分别给出准确的 `hosts.yml` 路径提示。
- [`tests/gateway.test.js`](../tests/gateway.test.js) 补充 Windows `%APPDATA%\GitHub CLI\hosts.yml` 自动解析用例，全套 `npm test`（2/2）通过。
