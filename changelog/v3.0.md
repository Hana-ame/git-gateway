# v3.0 — 零依赖纯 Node.js 运行时移植与只读仓库目录 `/repos`

> 发布日期：2026-11-27

## 新增（Added）

- **零依赖纯 Node.js（`>=18`）完整运行时**（`index.js`、`package.json`、`src/config.js`、`src/models.js`、`src/store.js`、`src/promptRenderer.js`、`src/gitProxy.js`、`src/githubClient.js`、`src/gitOps.js`、`src/app.js`）：使用 Node 原生 `http`、`fetch`、`crypto`、`child_process`、`fs` 实现 100% 路由与安全能力对齐，**0 第三方 npm 依赖、0 Python 依赖**（原 Python 实现已整体迁至 `python` 分支，`main` 只保留 Node.js 版）。
- **只读仓库目录接口 `GET /repos`**（`src/app.js`、`gateway/app.py`）：根据当前生效的 gitignore 风格规则（排除通配符与 `!` 取反规则并经 `isRepoAllowed` 二次校验）与 `REPO_ALIASES` 返回可用仓库列表及 `todo_url` / `prs_url`，供 Atlas 画布看板自动拉取。
- **Node 端到端回归测试**（`tests/gateway.test.js`）：使用本地真实裸 Git 仓库 + 本地 Mock GitHub HTTP 服务，覆盖 `/health`、`/repos`、Admin 鉴权与原子落盘、封禁 `git-receive-pack` 与 HPP 参数污染、八进制转义 `.github/workflows` CI 投毒与 `mode 120000` 符号链接拦截、真实推送 `<nickname>/<branch>` 与建 PR、以及 302 日志跳转不泄露 Token 与去 ANSI。

## 改进（Changed）

- **精简运行时容器镜像**（`Dockerfile`、`README.md`）：Docker 镜像切换为 `node:22-bookworm-slim`（仅装 `git` 与 `gh` CLI），彻底移除 Python 3 与 `venv`；服务优雅停机调用 `server.closeIdleConnections()`。

## 验证

- 本地执行 `node --test tests/gateway.test.js` 端到端全部通过；`python` 分支的 Python 实现同步补入 `/repos` 并通过 `python3 -m py_compile` 语法检查。
