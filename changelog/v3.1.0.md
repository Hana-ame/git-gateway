# v3.1.0 — 无 `gh` CLI 依赖凭据借用、`!` 屏蔽直连拦截测试与 `/admin/` 可视控制台

> 发布日期：2026-11-27

## 新增（Added）

- **纯 Node 宿主机 `gh` 凭据解析与分级回退**（[`src/config.js`](../src/config.js)、[`src/app.js`](../src/app.js)）：
  - `resolveGithubToken()` 优先借用宿主机凭据：先以零依赖 YAML 解析直读 `${GH_CONFIG_DIR}/hosts.yml`（`gh_hosts_yml`），再尝试 `GH_CLI_PATH` / `gh auth token`（`gh_cli`），均不可用时回退至 `GH_TOKEN` / `GITHUB_TOKEN`（`env/arg`）；
  - 两者均缺失时在 `/health` 返回 `github_token_hint` 与 `gh_config_dir`，明确提示挂载 `GH_HOST_CONFIG_DIR`、设置 `GH_CLI_PATH` 或配置环境变量 Token；Docker 镜像不再强制 `apt` 安装 `gh`。
- **内置零冲突管理员可视化网页**（[`src/adminUi.js`](../src/adminUi.js)、[`src/app.js`](../src/app.js)）：
  - 仅在 `GET /admin` / `GET /admin/` 且携带 `Accept: text/html`（非 `?format=json`）时返回可视化管理页面，不泄露任何服务端 Token，前端在 `sessionStorage` 输入 `GIT_GATEWAY_ADMIN_TOKEN` 后可管理全局与分仓 Prompt、TODO Markdown，查看 `/health` 凭据状态及 `/repos` 白名单；原有 JSON API 权限与接口行为 100% 保持不变。

## 测试与验证

- 扩展 [`tests/gateway.test.js`](../tests/gateway.test.js)：补充 `!alice/secret` 直访 `/todo` & `/patches` 拦截（`403`）、`hosts.yml` 无二进制借用与回退提示、`GET /admin/` HTML 可视页与 JSON `401` 隔离验证，`npm test` **2/2 全部通过**。
